# TelemetryMate

TelemetryMate is a power plant Equipment Maintenance System built with a React frontend, a Node.js/Express API, and a MongoDB database.

## Requirements
* Node.js and npm
* MongoDB

## Local Setup Steps

**1. Start the Backend**
* Open a terminal and navigate to the backend directory: `cd backend`
* Install backend dependencies: `npm install`
* Start the server: `npm start` (Server runs on http://localhost:5000)

**2. Start the Frontend**
* Open a new terminal and navigate to the frontend directory: `cd frontend`
* Install frontend dependencies: `npm install`
* Start the React app: `npm start` (App runs on http://localhost:3000)
